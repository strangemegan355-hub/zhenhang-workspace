3

核心业务页面完善 P0

Quotes 报价列表/详情/新建；Materials 物料 CRUD + 分类树；Work Orders 工单状态流转。确保"报价→审批→生产"核心链路完整可用。

4

端到端 MVP 闭环 P1

打通报价→审批→项目→工单完整流程；PDF/Excel 导出美化；基础 RBAC 权限校验（admin / sales / operator）。

🟡 第二阶段：功能增强（5-8 周）— 中优先级

5

公式引擎 UI 集成 P1

将 @zhenhang/formula-engine 能力通过 UI 暴露给用户——可视化公式编辑器、DAG 计算图预览、材料成本自动计算。

6

AI 辅助功能 P1

报价建议（基于历史数据）；生产异常检测；智能排产推荐。激活已有的 @zhenhang/ai-* 和 agent-* 包。

7

协同 & 通知体系 P2

消息中心（站内信）；审批流增强（多级审批）；响应式适配（平板/手机）。

8

测试体系补强 P1

Playwright E2E 测试覆盖核心流程；pytest API 集成测试；k6 性能基准测试。

🔴 第三阶段：规模化（9-16 周）— 低优先级

9

分布式 & 多租户 P2

多租户数据隔离；分布式任务调度（@zhenhang/distributed-runtime）；事件溯源（runtime-event-store）。

10

BI & 数据分析 P3

运营 BI 看板；成本趋势分析；产能预测。需要积累足够生产数据后才有意义。

11

CI/CD & 容器化 P2

GitHub Actions / GitLab CI；Docker Compose 一键部署；K8s Helm Chart；Prometheus + Grafana 监控。

12

正式发布 🚀 P3

生产环境部署；用户培训手册；运维 Runbook；数据备份策略。
