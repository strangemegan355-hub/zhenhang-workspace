2. Card / Table / Form / Status / Layout 重点重复点

  • Card：Dashboard 内存在多种相近卡片容器，建议统一 `IndustrialCard`。
  • Table：多个页面自建筛选栏、导出按钮、分页区，建议统一 `TableShell`。
  • Form：报价/成本/设置页表单字段重复校验模式，建议统一 `FormField` 与 `FormSection`。
  • Status：状态色、Badge、点状状态在多处硬编码，建议统一 `StatusBadge`。
  • Layout：App Shell、登录页、列表页、Dashboard 页面容器风格不完全一致，建议统一 `IndustrialPage` + `AppShell`。
