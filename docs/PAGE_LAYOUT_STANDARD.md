# 页面布局与交互规范

---

## 1. 标准工作区结构（列表页）

```
┌─────────────────────────────────────────────┐
│ PageHeader: 标题 + 一句话说明    [主操作]   │
├─────────────────────────────────────────────┤
│ FilterBar: 搜索 + 2–4 个高频筛选            │
├─────────────────────────────────────────────┤
│ 列表区: 表格 + 分页 + 批量操作（如有）       │
└─────────────────────────────────────────────┘
```

- 主操作最多 **1 个** 实心按钮（如「新建」），其余 secondary 或「更多」。  
- 危险操作（删除、反审核）需二次确认 + 权限。

---

## 2. 标准工作区结构（详情/编辑）

```
PageHeader（含状态 Badge）
├─ 左：分组表单区块
└─ 右（可选）：SideSummaryPanel 金额/状态/关联链接
底部固定栏：取消 | 保存草稿 | 提交（按业务）
```

- 保存中禁用按钮，防重复提交。  
- 错误保留已填字段。

---

## 3. 报价页（特殊）

- 单页连续操作：客户 → 行项目 → 汇总 → 预览/提交。  
- `/quotes/new` 若仅为 redirect，应导向统一工作台（📄 当前为 redirect，需验证目标）。

---

## 4. 导航

- 侧栏分组见 `menu.ts` V2.0；当前页高亮 + 面包屑（`app-shell` header）。  
- 返回列表：保留筛选状态（query string 或 session）。

---

## 5. 权限与空态

- 无权限：整页说明，而非空白。  
- 功能关闭（`accounting_enabled` 等）：菜单隐藏 + 深链友好提示。

---

## 6. 响应式

- 最小宽度 1280px 为管理端舒适区；表格允许横向滚动，不隐藏关键列。  
- 移动端独立 app，不要求 Web 全响应。
