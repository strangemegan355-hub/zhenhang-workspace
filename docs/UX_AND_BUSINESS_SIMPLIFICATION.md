# 业务与操作体验简化清单

> 主动产品设计整改记录。状态：**待实施 / 进行中 / 已验收**

---

## UX-001 产品库 vs 机型管理双入口（P1）

| 项 | 内容 |
|---|---|
| 当前设计 | 侧栏曾同时有「产品库」「机型管理」；报价可同时关联 `product_id` 与 `machine_id` |
| 不合理处 | 塑料机械销售同事需理解两套主数据；易重复维护规格与价格 |
| 对员工影响 | 选错数据源、报价与项目汇总不一致 |
| 建议 | **默认路径**：标准售卖走 Product + 售价模板；机型/BOM/选项组收进「高级配置」或合并为产品详情 Tab |
| 涉及 | `menu.ts`、`quotes/*`、`products/*`、`machines/*`、Quote API |
| 历史数据 | 保留 machine 关联，不删字段 |
| 风险 | 老报价仍指向 machine；需标签区分「标准产品报价 / 定制机型报价」 |
| 测试 | 场景 A + 回归 DEMO-Q-001 |
| 状态 | **进行中**：侧栏已隐藏机型路径；新建报价默认只要求产品，机型/BOM 收入「高级」折叠区（2026-10-23） |

## UX-002 报价与对客报价两个菜单（P2）

| 项 | 内容 |
|---|---|
| 当前设计 | 「报价中心」与「对客报价」并列 |
| 不合理处 | 员工不知从何进入；可能重复创建 |
| 建议 | 合并入口：列表内 Tab「内部 / 对客」；或将对客作为报价详情的一种视图 |
| 涉及 | `menu.ts`、`/quotes/customer` |
| 状态 | **进行中**：对客报价侧栏隐藏；报价中心页头提供「对客报价视图」入口 |

## UX-003 财务三个菜单（P2）

| 项 | 内容 |
|---|---|
| 当前设计 | 账目明细、收支台账、供应商台账 |
| 建议 | 保留三页但统一「财务中心」子 Tab + 一致筛选；首页只显示「待收款/待付款」 actionable 卡片 |
| 状态 | **进行中**（2026-10-23）：侧栏合并为「财务中心」单入口；三页加 `FinanceSubNav`；工作台加财务待办卡。运行验收 ☐ |

## UX-004 项目重复录入客户/金额（P1）

| 项 | 内容 |
|---|---|
| 当前设计 | 项目有 customer；报价也有 customer；金额在报价与成本/利润多处展示 |
| 建议 | 新建项目优先从已通过报价生成；金额只读引用报价 total + 实际成本增量 |
| 涉及 | `project_service`、`/projects` UI |
| 状态 | **进行中**：前端选报价锁定客户；**服务端** `create/update_project` 亦强制客户与报价一致（冲突 400）；summary 已可返回关联报价 |
